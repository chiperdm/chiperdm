### 🌐 Verve Browser
Концепт кастомного веб-браузера, где всё заточено под скорость работы и управление без лишних кликов.

* 🖥️ Адаптирован под Desktop и Mobile
* 🌑 Строгая темная дизайн-система (`#16171B` / `#1E2026`) с неоновым коралловым акцентом
* 📑 Вертикальный сайдбар для вкладок вместо классической верхней шапки
* ⌨️ Плавающий **Command Bar** (`Ctrl + K`) для быстрого поиска и навигации
* ⚡ Управление через горячие клавиши на ПК и жесты на смартфонах
