# Привет! Я Flutter / Dart разработчик 👋

Создаю кроссплатформенные приложения для **Android, iOS и Desktop**. Мне нравится собирать проекты с нуля — от идеи и дизайна в Figma до бэкенда, базы данных и релиза готового продукта.

## 🧠 Как я пишу код

Я не просто заставляю фичи работать, а думаю наперед. Пишу код так, чтобы проект можно было легко масштабировать и поддерживать через полгода.

Ценю переиспользуемые компоненты, слежу за плавностью UI и не раздуваю кодовую базу там, где можно сделать проще.

Мне нравится самостоятельно проходить весь цикл разработки: **идея → архитектура → дизайн → разработка → backend → тестирование → релиз**.
